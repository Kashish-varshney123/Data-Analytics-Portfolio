# Urbancart Superstore – Retail Sales Analysis

## Project Overview
This project analyzes retail transaction data to identify sales trends, top-performing products, and regional performance.

## Tools Used
- SQL
- Excel (Power Query)
- Power BI

## Dataset
- 10,000+ retail transaction records
- 12 months of sales data

## Key Analysis
- Total Sales, Total Orders, Quantity Sold
- Average Order Value
- Top Products and Regions

## Dashboard
Power BI dashboard includes:
- Sales trends
- Product-wise and region-wise analysis
- Interactive slicers

## Insights
- Identified top 5 revenue-generating products
- Highlighted top 3 regions contributing to maximum sales
